## The entry

> It's 3 AM — my keys are asleep, my screen is dark, and your 'just one more trade' is exactly why I have a bedtime.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`. Deterministic: no network, no randomness, no time dependence. The program self-checks the competition gate (1–200 characters, not only white space, single line) before writing.
